= Auch bei Agentic Coding ist die Kapazität endlich
:stem: latexmath

Aktuell höre und lese ich immer, dass mithilfe der künstlichen Intelligenz, den Large Language Modellen für Agentic Coding und Tools wie Claude Code oder Copilot Software Commodity geworden sei.
Doch die Idee, dass Code mit Agentic Coding zu erzeugen oder zu ändern nichts mehr kostet, ist eine Lüge, wenn auch eine angenehme.
Und wer behauptet, dass all dies jetzt nichts mehr kostet und wir einfach von Sprache zu Sprache und von Framework zu Framework springen, unterliegt einem Selbstbetrug.

Der Grund dafür ist einfach. Die Zeit stem:[t] ist endlich. Für alles, für dessen Durchführung stem:[t(A) > 0ms] gilt, gilt auch, dass für zwei voneinander abhängige Aufgaben stem:[A] und stem:[B] gilt, dass stem:[t(A) + t(B) > min(t(A), t(B))] gilt.

Und das für jedes stem:[\forall A: t(A) > 0ms] gilt, ergibt sich allein schon durch die Beschränkung jeder Signalgeschwindigkeit durch die Physik.

Und ein weiterer Punkt, der übersehen wird ist, dass Software mehr als Code ist.
Sie ist codifiziertes Wissen und dieses wird immer zusammen mit der Software gewonnen und oft hart erarbeitet.

Daher: Zeit ist endlich, jede Ressource ist endlich.
Genauso wie wir sterblich sind.
Und die Zukunft war nie eine Extrapolation von Entwicklungen.

Was sich ändert, ist der Maßstab.
Und wenn ihr jemanden findet, der sagt: "Man müsse nicht mehr wegen KI...", dann sagt mir Bescheid.
Diese Person ist zum einen unsterblich und verfügt über unbegrenzte Ressourcen.
Ich brauche diesen Kontakt.
