= Optionen, Argumente und Operanden: Standards für Command Line Interface
:stem: latexmath

Optionen, Argumente und Operanden: Standards für Command Line Interface kann jetzt geschrieben werden.

== tl;dr

---

Das Terminal öffnet sich und wir tippen, um Programme aufzurufen, die für uns arbeiten.
Befehle wie `ls -lah` oder `claude --model claude-sonnet-4-6` sind uns in Fleisch und Blut übergegangen.
Doch was ist das, was wir dort tippen nach dem Namen des Programms und nach welchen Konventionen sollte man sich richten, wenn man selber Programme schreiben will?

In diesem Artikel beschäftige ich mich mit den Grundlagen der Steuerung von Command Line Interfaces über Optionen und Argumente sowie der Klärung der relevanten Standards.

== Optionen, Operanden und Argumente an lebenden Beispielen

Sehen wir uns ein paar Beispiele von Aufrufen von Command Line Interfaces, ab jetzt verwende ich nur noch den Begriff Cli für Command Line Interfaces, an.

[#listing-sort,reftext="Listing 1"]
.Sortierung von Textdateien mit `sort`
[source,shell]
----
$ cat data.txt
cat data.txt
Peter	180
Agit	175
Anna	175
Susi	195
$ sort -r \     <1>
       -k 2 \   <2><3>
       data.txt <4>
Susi	195
Peter	180
Anna	175
Agit	175
----
<1> Umgekehrte Sortierung der Daten
<2> Sortierung soll nach einem bestimmten Feld erfolgen
<3> Verwendung von Feld 2 für die Sortierung
<4> Zu sortierende Datei

In <<listing-sort>> werden Datensätze nach dem zweiten Feld pro Datensatz sortiert, sodass die Personen nach der Größe sortiert ausgegeben werden können.
